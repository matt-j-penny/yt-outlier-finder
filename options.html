YT Outlier Finder

Find outlier videos and save them to Content OS.

Settings How to use it

Connect Content OS

The + Idea and Save inspo buttons save straight to your Content OS account. They need an API key to do that.

  1. Open the API page in Content OS and create a key.
  2. Copy it (it starts with cos_) and paste it below.

Install vidIQ

Outlier scores come from the free vidIQ Vision for YouTube extension. Without it, the outlier filter has nothing to read and will hide every video.
