YT Outlier Finder Settings

Content OS

Saved videos, titles and thumbnails go to your Content OS Inspiration page. Create an API key on the Content OS API page and paste it here.

Required: The vidIQ Vision for YouTube Chrome extension must be installed for outlier scores (the extension reads the "X x" badges that vidIQ adds to video cards).

On YouTube: hover a video and click Save to save it with its outlier score. Right-click a video for Save title to Content OS or Save thumbnail to Content OS.
